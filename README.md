# jHBV

HBV-96 rainfall-runoff model extracted from [SYMFLUENCE](https://github.com/DarriEy/SYMFLUENCE).

Dual-backend (JAX + NumPy) implementation of the Lindstrom et al. (1997) HBV-96 model
with snow, soil moisture, response routine, and triangular routing.

## Installation

```bash
pip install jhbv
```
